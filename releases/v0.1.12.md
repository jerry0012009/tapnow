# TapNow Companion v0.1.12

Windows Chrome 试用版（Pre-release），发布于 2026-09-08。
用于真实 PC 试用，不表示已完成 Windows 实机验收或完整工作空间产品验收。

## 下载与安装

下载本页附件 **tapnow-companion-0.1.12-chrome.zip**，不要下载 GitHub 自动生成的
“Source code”压缩包。备份功能不需要 Node.js、npm 或 API Key。

1. 在 Windows 中右键 ZIP，选择“全部解压缩”。放到固定目录，例如
   `D:\TapNow-extension\`，不要运行在压缩包内部。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择**直接包含 manifest.json 的文件夹**。确认扩展名为 TapNow Companion，
   版本为 0.1.12。若已安装旧版本，先停用旧版本，避免重复注入。
5. 登录 TapNow，打开想备份的画布，刷新该页面，点击页面中的“备份”入口。
6. 在备份中心选择一个新建的本地文件夹，例如 `D:\TapNow-backups\`，
   接受 Chrome 写入授权。该目录与扩展安装目录分开。
7. 选择已打开的画布，点击“扫描画布”；核对数量后设置新增容量上限，
   点击“开始 / 增量补齐”。

此版本不是 Chrome Web Store 安装包，不能通过双击 ZIP 一键安装。
企业策略禁用开发者模式时，需要设备管理员允许加载解压扩展。

## 试用重点

- 目录内生成 `tapnow-backup/<画布 ID>/`，包含节点、连线、引用、资源清单与原文件。
- 保持 Chrome、TapNow 标签页和独立备份页打开，电脑不要休眠。
- 单个下载失败不阻塞其他目标；`partial` 表示本轮有缺口，不是全部成功。
- 暂停后可继续；再次选择同一目录并扫描可校验、复用、修复损坏文件、重试缺口。
- 默认新增上限为 20 GiB；这不是磁盘剩余空间估值，实际需要预留临时文件空间。
- 独立网页查看器不在 ZIP 内；备份不要求运行查看器。

本次 Windows 试用用于继续核对实际 PC 的目录授权、文件写入和恢复表现。

## 已知限制

- 当前范围为已打开的单画布，不支持自动枚举整个工作空间和所有子画布。
- 32 个真实失败目标尚未恢复；历史/任务/缓存的完整恢复链及覆盖核对尚未完成。
- 尚无用户可撤销的“无需下载名单”界面。
- 不承诺关闭 Chrome 后继续下载，也未完成强制杀进程、磁盘满及目录撤权的实机矩阵。
- Windows/Mac 原生目录授权尚待实机验证；不能把 Linux 成功等同于全平台验收。
- 既有副驾驶仍保留，默认关闭 LLM；备份流程不会调用 LLM。
