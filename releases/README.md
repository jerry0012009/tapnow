## 安装与更新

1. 下载所需扩展 ZIP，解压到固定目录。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压目录。
4. 更新时可替换原扩展目录中的代码，再点击重新加载；或停用旧版并加载新目录，避免重复启用同一插件。
5. 关闭旧扩展页面，重新打开。备份目录不需要删除或重建。

这是个人试用预发布包，不是 Chrome Web Store 安装包。
普通用户无需安装 Node.js 或运行构建命令。

## 资产备份

登录并打开目标 TapNow 画布，点击“备份此画布”，确认备份页显示的画布名称、ID 和来源标签页。
项目列表只是入口，需要打开具体画布。选择本地目录并授权，扫描后设置本轮新增上限，
点击“开始 / 增量补齐”，保持 Chrome 与备份页打开。

单资源失败会记录并继续；再次选择相同目录扫描可复核、复用和补漏。
备份不依赖 LLM，不压缩原文件。当前支持单画布，尚不是完整工作空间枚举产品。

## 本地资产库

Backup 内置“查看本地备份”，选择备份总目录、`tapnow-backup` 或具体画布目录，
即可浏览节点、连线、文字、提示词、引用和资源状态。
图片、视频、音频从本地文件按需加载，不需要登录 TapNow，也不需要启动服务器。

点击“核对完整性”重新读取文件并验证大小和 SHA-256，可导出 JSON 核对报告。
清单保存比例不是本次重新核对的结果；本地核对也不证明云端没有遗漏。

服务器版查看器仍可使用，见 [部署与数据格式](../docs/BACKUP_VIEWER.md)。

## 副驾驶

Companion 不包含备份功能或备份权限，只提供节点检测和可选 LLM 审阅。
LLM 默认关闭；API Key 保存在本机扩展存储，不上传本仓库。
