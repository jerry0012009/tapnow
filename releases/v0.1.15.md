# TapNow Companion v0.1.15

本版拆分为两个独立 Chrome 扩展，适用于不同使用人群。

## 下载

- `tapnow-companion-0.1.15-chrome.zip`: 副驾驶，节点检测与可选 LLM 审阅。
- `tapnow-backup-0.1.15-chrome.zip`: 资产备份、备份中心、本地画布查看器与完整性核对。

安装方式：分别解压，在 `chrome://extensions` 开启开发者模式，分别加载两个解压目录。只需要其中一个功能时，不必安装另一个。

## 资产备份扩展

在具体 TapNow 画布中点击“备份此画布”，或点击备份扩展的工具栏按钮。备份页显示明确画布名称、ID、来源标签页；项目列表只作为入口，不能作为备份对象。

点击“查看本地备份”后选择备份总目录。查看器支持：

- 选择具体本地画布
- 全部节点、文字节点、连线、引用和资源状态
- 图片、视频、音频按需从本地文件加载
- 文件大小与 SHA-256 重新核对
- 缺失、损坏、清单不一致、悬空连线和孤立引用报告
- 导出 JSON 核对报告

查看器只读取用户主动选择的本地目录，不访问 TapNow 云端，不需要启动服务器。

## 副驾驶扩展

只注入副驾驶入口和节点检测面板，不包含备份按钮、备份权限或本地资产查看器。副驾驶设置和 LLM 审阅仍保留。
