# 本地资产查看器

这是独立于 Chrome 插件的只读 Node.js 服务。它读取插件写入的备份目录，
不要求 TapNow 登录、不调用 LLM、不从云端补图片，不会修改画布或媒体。

## 启动

需要 Node.js 22+。在仓库目录安装依赖，然后指定一个画布的备份根目录：

```bash
npm ci
npm run viewer -- "/absolute/path/tapnow-backup/canvas-id"
```

浏览器打开 http://127.0.0.1:8787/ 。必须指定包含 `report.json`、
`nodes.ndjson` 等文件的画布目录，不是其上层目录。默认监听回环地址。

Windows PowerShell 使用相同命令，目录可以写成：

```powershell
npm run viewer -- "D:\Backups\tapnow-backup\canvas-id"
```

Mac 使用相应的 `/Users/...` 路径。源码没有依赖 Linux 专属目录 API，
但本轮真实浏览器测试在 Linux Chromium 上进行，不能代替 Mac/Windows 实机验收。

## 展示内容

- **全部节点（默认首屏）**：全部真实节点占位及连接，按保存的原始位置和父分组
  相对坐标展示；不修改源数据，不提前加载媒体。
- **当前关系**：选中节点及直接上游、下游；重新布局便于阅读。
- **节点详情**：提示词、文本、生成参数、属性、完整节点和连线 JSON。
- **全部节点类型**：图片、文字、视频、音频、附件、分组及未知类型不做排除；
  文字节点直接显示摘要，详情保留完整文字及换行，搜索包含完整文字。
- **资源列表**：当前、备选、历史和其他引用，包含每个来源字段路径。
- **按需预览**：初始不请求媒体；点击节点即加载已保存的当前资源，无须二次点击。
  详情中可继续选择其他历史和备选。图片缩略图在内存生成。
- **验收说明**：产物来源、目标/引用/去重文件的独立统计、失败和校验报告。

原始位置视图忠实保留源画布可能存在的重叠。当前关系视图提供可读的重新布局，
不能把该布局误称为云端原始位置。端点缺失的连线保留在原始 JSON 和诊断中，
不虚构节点及位置。长历史列表独立滚动。

## 插件产物格式

```text
<用户选择目录>/tapnow-backup/<canvas-id>/
  canvas.json
  nodes.ndjson
  connections.ndjson
  references.ndjson
  assets.ndjson
  report.json
  verification.json           # 独立复核命令生成，可选
  objects/sha256/<前两位>/<完整哈希>
  partial/                    # 临时文件，不计为成功
  runs/<run-id>/
    snapshot.json
    report.json
    assets.ndjson
```

每个引用通过 `assetId` 关联唯一下载目标，再通过 `file` 与 `sha256` 关联磁盘文件。
多个 URL/file ID 可能最终对应相同字节；目标数与物理文件数不必相等。
预览仅允许已保存清单中的文件。增量期间保留文件、哈希和字节数的 `queued`
对象可预览，并明确显示“已保存 · 待复核”，不计入本轮已验证数。
HTML/SVG 等未支持类型作为附件处理。无需公开整个备份目录。

该结构是当前单画布实现，不是规划中的全工作空间归档格式。增量运行保留旧目标，
本次未发现的目标标记 `notInLatestScan`，仍校验已有文件或重试旧地址。每轮结果
与快照单独保留；当前尚无历史快照切换界面，旧节点的全部引用需查对应 run 快照。

## 独立校验

```bash
npm run backup:verify -- "/path/to/canvas-backup"
```

逐个读取实际物理文件，复核字节数和 SHA-256，并检查每条已验证目标。
第二个目录参数可作基线比较：目标集合、哈希、节点和连线原始 JSON。
校验脚本不下载媒体；失败返回非零退出码。`passed` 表示已保存文件及所执行
对账通过，不意味着未知历史和未保存资源已完整。

应在插件任务结束后执行，避免对仍在变动的清单生成报告。查看器只展示与当前
结束任务 run ID、已验证数匹配的复核文件；它是校验时点的证据，不是持续防篡改。

## 访问与安全

服务没有内建登录。备份包含团队私有素材、提示词和来源地址，不能作为公开
素材站发布。远程访问应通过可信网络、认证反向代理或 SSH 隧道。
需要监听其他接口时可配置 `HOST`/`PORT`，部署者需负责访问控制。

```powershell
$env:HOST="127.0.0.1"
$env:PORT="8787"
npm run viewer -- "D:\Backups\tapnow-backup\canvas-id"
```

服务器仅提供清单内的已验证媒体，并检查路径和符号链接。图形和图标库随本地
依赖安装，不请求 CDN；字体使用系统字体。初次 `npm ci` 需要联网，查看已有
备份不依赖 TapNow 或其他外部网络。
