- **真实插件全量目录写入已通过本样本验收**：2,489 个目标全部尝试，2,457 个成功，
  与原执行器基线的目标集合、文件哈希、节点和连线逐项一致。原报告中

- 独立复核 1,792 个物理文件、11,456,977,999 字节，无损坏或缺失。
- 独立网页直接读取插件结果；真实全节点总览、原始坐标、关系导航、按需本地图片、

- 所有节点类型均保留，不按图片过滤。真实主样本只有图片和分组；
  其他类型有内部回归，但不计作真实账户媒体类型验收。
- 58 项自动化测试通过；备份 TypeScript 检查和 MV3 构建通过。

## 已修复的问题

| 问题 | 修复 |
| --- | --- |
| 页面 fetch/CORS 与防盗链导致原件无法下载 | 扩展页直接 fetch；DNR 对自身媒体请求设置真实 Referer，不发送主站 Bearer |
| 下载流被分块次数或整文件内存限制截断 | 4 MiB Range 循环、流式写入/哈希，检查偏移、长度、总数和 ETag |
| URL 与旁边 file ID 被错误合并 | 保持独立目标，下载后按内容哈希去重，不假定两个变体相同 |
| 重复计入同一个 URL 字段引用 | 每个实际字段只生成一次引用 |
| 只按资源首个所属节点归类 | 使用完整 references 清单关联每个引用节点 |
| 原始位置被关系布局修改 | 独立保存坐标副本，全部真实节点逐点回归对照 |
| 全量总览缩小时几乎不可见 | 缩小时加强实际节点与连线对比，点击后再读取本地媒体 |
| 点击节点后仍需二次点击图片 | 单击节点即加载本地当前资源，失败时显示实际状态与原因 |
| 增量复核时已保存文件无法预览 | 保留文件/哈希/大小的待复核对象仍可读取，明确标记而不冒算本轮验证成功 |
| 增量中断留下 queued 导致重复下载 | 只要保留文件及哈希，就重新读取验证后复用 |
| 新扫描遗忘旧目标 | 合并旧目标，标记 notInLatestScan，校验本地或继续尝试旧来源 |
| 旧运行缺少最终目标结果 | 每轮保存 assets.ndjson，与原始 snapshot、report 分开保留 |
| 磁盘预算冒用浏览器存储估值 | 移除该口径，明确由用户设定新增写入上限 |
| 本地查看器路径/格式风险 | 清单约束、realpath 防逃逸、长度检查、Range/HEAD、MIME 白名单、CSP |

## 仍不能签署最终验收的事项

1. **失效对象恢复还不充分。**32 个 file ID 的已实现来源仍 404；没有证明所有历史、
   任务、旧域和缓存恢复路径均已检查。不能将其描述为“永久删除”或完整备份。
2. **全工作空间与历史完整性仍未知。**当前可选择已打开的单画布；尚无项目树、
   全工作空间/子画布枚举，未完成页面历史列表与 API 独立对账，尚不支持未保存运行时
   blob/data URL 和任意第三方附件的授权下载。
3. **人工名单未完成。**用户确认、理由、证据、撤销、强制重试的“无需下载名单”
   尚无界面与完整状态流程；没有自动把失败加入名单。
4. **一致性与恢复还需加强。**每个文件原子关闭不等于跨多个清单的事务；尚无
   提交日志重建、扫描期间协作变化检测。保留旧目标已实现，但云端状态/tombstone
   与历史快照切换查看尚未完整实现。
5. **生命周期和平台矩阵未全验。**本机暂停恢复、原生目录写入可用，但操作系统
   重启、浏览器进程被杀、目录移动/撤权、跨浏览器同时写同一目录、Mac/Windows
   原生目录授权仍需实测。Web Lock 只协调同源浏览器环境。
6. **下载异常策略还有边界。**目前固定四次退避，尚未按 Retry-After 调整429；
   对拒绝 Range 的非200/206服务器还缺少完整 GET 降级；ETag 缺失时不能证明
   不同分段期间云端内容未变；MIME与哈希不等价于全部格式的原始性证明。
7. **容量估计和临时空间。**纯扩展无法可靠获知所选文件系统剩余字节；
   新增预算包含运行中流式占用，但不能代替操作系统可用空间检查，也不能保证
   临时副本和原子写入的峰值正好等于最终去重占用。空间/权限失败会停止队列。
8. **远程查看器需部署访问控制。**默认只监听回环地址；没有内建账号认证，
   当前远程测试入口只适用于用户确认的可信环境，不能作为公开素材库。

## 判断

“插件无法完成此前执行器同等结果”和“缺少可用的真实关系画布”两个本轮重点，
已经有真实全量运行及截图/磁盘复核证据。完整产品范围仍未全部完成，尤其是
失效资源恢复、历史覆盖、工作空间范围和人工名单，不能以本次单画布成功替代。

详细真实数量及失败含义见 [真实插件验收](REAL_BACKUP_TEST_2026-09-08.md)。
