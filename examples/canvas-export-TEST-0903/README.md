# Complete Canvas Example

This directory is a complete export of one authorized TapNow canvas captured on
2026-09-03.

It includes:

- `canvas.json`: canvas metadata plus embedded node and connection data.
- `nodes.json`: node API response.
- `connections.json`: connection API response.
- `media-manifest.json`: source media and local filenames.
- `media/`: two downloaded original JPEG files.
- `summary.json`: counts and export metadata.

The example intentionally contains real prompts, generated text, node IDs and
generated images so the data shape can be tested end to end. It contains no
login credentials, browser profile, access token, refresh token, Cookie header
or network capture.
